SpiderMaps pre-rendered navigation voice clips
=============================================

Export clips from Chatterbox Multilingual, KugelAudio, or any other licensed TTS model into this folder.

Supported formats:
- mp3
- wav
- ogg

Recommended filenames:
- nav_started.mp3        -> "Navigation started."
- turn_left.mp3          -> "Turn left."
- turn_right.mp3         -> "Turn right."
- continue_straight.mp3  -> "Continue straight."
- u_turn.mp3             -> "Make a U-turn."
- roundabout.mp3         -> "Enter the roundabout."
- rerouting.mp3          -> "Rerouting."
- arrived.mp3            -> "You have arrived."
- in_5_meters.mp3        -> "In 5 meters."
- in_10_meters.mp3       -> "In 10 meters."
- ...
- in_950_meters.mp3      -> "In 950 meters."

The app plays these clips only when navigation sound is enabled.
For example, "Turn left in 100 m" plays:
1. turn_left.mp3
2. in_100_meters.mp3

Keep clips short, loud, and dry. Avoid background music or reverb for driving clarity.
